# What The Craft is

> **A set of hard rules for building and running an application end-to-end with Claude** — so a
> vibe-coded project stays understandable, testable, safe to change and trustworthy, from the first commit
> to production with real users. Not a framework, not a library: a doctrine the agent reads and follows.

## Who it's for

A **single developer** building a real application **with AI as the pair** — not an enterprise team with
dedicated ops and QA. "Solo" still means several writers: you'll run **several Claude sessions** on one repo,
so the coordination rules (issues, short branches, push/pull discipline) matter from the second session on
(→ [05](05-git-and-deployments.md)).

## How to start

1. Install **Claude Code** (desktop or CLI).
2. Fill in the [brief](index.html#brief) — it asks what changes the architecture: languages, MVP,
   monetization, tone.
3. Attach The Craft to the project as `docs/rules/` and start from [Day 0](07-new-project-day-0.md).

You don't have to memorize anything — the agent reads the rules. If you read one file, read the
[Decalogue](00-commandments.md).

These pages are deliberately terse. **Explanations, examples and the stories behind each rule:**
[thecraft.jakub.solutions](https://thecraft.jakub.solutions).
